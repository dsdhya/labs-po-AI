# Лабораторная работа №3: Метрики качества, кросс-валидация и пайплайны

## 1. Описание проекта

Освоение применение математического аппарата метрик качества и строгой методологии тестирования ML-моделей. Обучение в сборе индустриального конвейера (Pipeline) для предотвращения утечки данных (Data Leakage) и автоматизация подбора гиперпараметров с помощью алгоритмов поиска.

## 2. Структура

**Структура репозитория:**

1. `README.md` — краткое описание проекта, выбранного датасета и итоговых аналитических выводов.
2. `WA_Fn-UseC_-Telco-Customer-Churn.csv` - датасет по оттоку телеком-клиентов (https://www.kaggle.com/datasets/palashfendarkar/wa-fnusec-telcocustomerchurn)
3. `lab3.ipynb` — Jupyter Notebook с полностью исполненным кодом, построенными графиками и текстовыми Markdown-пояснениями к каждому этапу.
4. `requirements.txt` — зафиксированные зависимости виртуального окружения.

## 3. Выбор датасета

Был выбран датасет по оттоку телеком-клиентов - https://www.kaggle.com/datasets/palashfendarkar/wa-fnusec-telcocustomerchurn
