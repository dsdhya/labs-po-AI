# Лабораторные работы по дисциплине «Искусственный интеллект»

Репозиторий содержит выполненные лабораторные работы по машинному обучению и анализу данных.

## Структура репозитория

- **[`lab1/`](./lab1/)**: Лабораторная работа №1 — «Введение в машинное обучение и подготовка данных».
  - Классификация клиентов банка на открытие депозита с использованием алгоритма Random Forest.
  - Разведочный анализ (EDA), кодирование признаков, стандартизация.
  - Точность модели (Accuracy): ~79.1%.

- **[`lab2/`](./lab2/)**: Лабораторная работа №2 — «Метод k-ближайших соседей и непараметрические методы регрессии».
  - Прогнозирование рыночной стоимости автомобилей с пробегом (`Used Car Price Dataset`).
  - Исследование влияния параметра $k$ в kNN на переобучение (Bias-Variance tradeoff).
  - Сравнение метрик расстояния Минковского ($p=1$ и $p=2$).
  - Ядерная регрессия Надарая-Ватсона с подбором параметра ширины окна $\gamma$.
  - Визуализация «Реальные vs Предсказанные значения» и бизнес-выводы.
