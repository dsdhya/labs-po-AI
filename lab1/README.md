# Лабораторная работа №1: Введение в машинное обучение и подготовка данных

## 1. Описание проекта
Приминенеи навыков работы с базовым инструментарием Data Science (Python, Pandas, Scikit-learn) путем самостоятельного проведения полного цикла аналитики и построения модели классификации на основе реальных экономических данных Kaggle.

## 2. Структура
Структура репозитория:

- `README.md` — краткое описание проекта, выбранного датасета и итоговых аналитических выводов.
- `bank.csv` — датасет маркетинговой кампании банка (https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset).
- `lab1.ipynb` — Jupyter Notebook с полностью исполненным кодом, построенными графиками и текстовыми Markdown-пояснениями к каждому этапу.
- `requirements.txt` — зафиксированные зависимости виртуального окружения.

## 3. Выбор датасета
Был выбран датасет маркетинговой кампании банка (Bank Marketing Dataset) — https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset

## 4. Вывод
Обученная модель достигла точности классификации 79.10%, эффективно определяя склонность клиента к открытию депозита.
